# El Despertar del Héroe
Juego hecho con el lenguaje java para ser jugado en la terminal

## Requisitos
Una versión moderna de java y el acceso a una terminal, como el CMD, PowerShell o la integrada en VSC

## Cómo ejecutarlo
Para ejecutarlo se clona el repositorio desde una terminal con:
git clone https://github.com/dachete/El_despertar_del_heroe_DavidH.git
Después se accede a la carpeta con el comando cd, y se compilan las clases del juego para generar los archivos .class necesarios con javac *.java. 
Por último, se lanza el programa con java Main.
